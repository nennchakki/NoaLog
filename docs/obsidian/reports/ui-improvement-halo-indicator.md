## 概要

HaloIndicatorは、NoaLogのキャプチャ状態を視覚的に示すウィジェット。「メカニカルな装置」をモチーフとした二重円＋セグメントデザイン。

**実装ファイル**: `/src/ui/widgets/halo_indicator.py`

## デザイン構成

```
     ████○○○○○○○
   ████○○       ○○
  ████○  ○○○○○   ○○
  ███○○ ○○   ○○  ○○
   ○○ ○○  ○  ○○ ○○
   ○○  ○○   ○○  ○○
    ○○   ○○○○○   ○○
     ○○         ○○
       ○○○○○○○○○

████ = 青いセグメント（90°〜180°、左上）
○○○ = 白い外側リング
○○○ = 薄い青の内側リング
 ○  = 中心のリング
```

| 要素 | 説明 | 色 |
|------|------|-----|
| 外側リング | 白い完全なリング（メカニカルな輪） | #FFFFFF |
| 内周リング | 薄い青の同心リング | #A7E4FF (accent_light) |
| セグメント | 左上90°〜180°の噛み合い部分 | #63C6FF (accent) |
| 中心リング | 青いリング（塗りつぶしではない） | #63C6FF (accent) |

## 4つの状態

| 状態 | Enum値 | アニメーション |
|------|--------|--------------|
| IDLE | `idle` | なし（静止） |
| PROCESSING | `processing` | セグメント回転（2秒/周） |
| SUCCESS | `success` | パルス（600ms） |
| FAILED | `failed` | フェード（480ms） |

## アニメーション詳細

### PROCESSING（セグメント回転）

```python
# 60fpsで滑らかな回転
update_interval = 16  # ms
steps_per_rotation = rotation_duration / update_interval
rotation_step = 360.0 / steps_per_rotation

def _update_rotation(self):
    self._rotation_angle = (self._rotation_angle + self._rotation_step) % 360.0
    self.update()
```

## 描画処理

```python
def paintEvent(self, event):
    painter = QPainter(self)
    painter.setRenderHint(QPainter.RenderHint.Antialiasing)
    painter.setOpacity(self._opacity)

    center = QPointF(self.width() / 2.0, self.height() / 2.0)
    widget_radius = min(self.width(), self.height()) / 2.0

    # 各要素の半径計算
    center_ring_radius = widget_radius * self.CENTER_RING_RATIO * self._scale
    outer_ring_radius = widget_radius * self.OUTER_RING_RATIO * self._scale
    inner_ring_radius = widget_radius * self.INNER_RING_RATIO * self._scale

    # 描画順序
    self._draw_white_outer_ring(painter, center, outer_ring_radius)
    self._draw_blue_inner_ring(painter, center, inner_ring_radius)
    self._draw_blue_segment(painter, center, outer_ring_radius, inner_ring_radius)
    self._draw_center_ring(painter, center, center_ring_radius)
```

## 使用例

### 基本的な使用

```python
from ui.widgets.halo_indicator import HaloIndicator

halo = HaloIndicator()
halo.start_processing()  # 回転開始
```

### シグナル接続

```python
def on_state_changed(state: str):
    print(f"Halo state: {state}")

halo.state_changed.connect(on_state_changed)
```

### キャプチャフローとの連携

```python
# キャプチャ開始時
halo.start_processing()

# キャプチャ成功時
halo.show_success()
# → 600ms後に自動でIDLEに戻る

# キャプチャ失敗時
halo.show_failed()
# → 480ms後に自動でIDLEに戻る
```
