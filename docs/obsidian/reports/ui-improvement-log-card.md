## 概要

LogCardは、タイムライン上の各ログエントリを表示するカード型ウィジェット。話者情報、本文、バッジ、マルチセレクト機能を提供。

**実装ファイル**: `/src/ui/widgets/log_card.py`

## カード状態

| 状態 | Enum値 | スタイル |
|------|--------|---------|
| NORMAL | `normal` | 白背景、透明ボーダー |
| HOVERED | `hovered` | #F0F7FF背景、薄いボーダー |
| SELECTED | `selected` | #E5F4FF背景、#63C6FFボーダー |
| MULTI_SELECTED | `multi_selected` | #F0F7FF背景、#A7E4FFボーダー |

## マルチセレクト

```python
def set_multi_select_mode(self, enabled: bool):
    """マルチセレクトモードの切り替え"""
    self._multi_select_mode = enabled
    self._checkbox.setVisible(enabled)

def is_checked(self) -> bool:
    return self._checkbox.isChecked()

def set_checked(self, checked: bool):
    self._checkbox.setChecked(checked)
```

## イベント処理

```python
def mousePressEvent(self, event):
    if event.button() == Qt.MouseButton.LeftButton:
        self.clicked.emit()

def mouseDoubleClickEvent(self, event):
    if event.button() == Qt.MouseButton.LeftButton:
        self.double_clicked.emit()

def enterEvent(self, event):
    if self._state == CardState.NORMAL:
        self.set_state(CardState.HOVERED)

def leaveEvent(self, event):
    if self._state == CardState.HOVERED:
        self.set_state(CardState.NORMAL)
```

## 使用例

### 基本的な使用

```python
from ui.widgets import LogCard, CardState
from models import LogEntry

entry = LogEntry(
    speaker_name="Alice",
    speaker_org="Engineering",
    body_text="Hello, this is a test message.",
    timestamp=datetime.now()
)

card = LogCard(entry)
card.clicked.connect(lambda: print("Card clicked"))
```

### マルチセレクト

```python
# マルチセレクトモード有効化
card.set_multi_select_mode(True)

# チェック状態の監視
card.checkbox_toggled.connect(lambda checked: print(f"Checked: {checked}"))

# 選択状態の取得
if card.is_checked():
    selected_entries.append(card.get_log_entry())
```
