## 概要

## ヘルパー関数

```python
from ui.styles.tokens import get_color, get_spacing, get_spacing_int

# 色を取得
accent = get_color("accent")  # "#63C6FF"

# スペーシングを取得
padding = get_spacing("space_4")  # "16px"

# スペーシングを整数で取得
margin = get_spacing_int("space_4")  # 16
```

## QSS統合

`noa_theme.qss`でトークンを直接使用：

```css
QMainWindow {
    background-color: #F6F1E6;  /* bg_light */
}

QPushButton#primaryButton {
    background-color: #63C6FF;  /* accent */
    border-radius: 10px;        /* radius_md */
}
```
