# プロジェクト計画書: NoaLog

## 概要
- **目的**: ゲーム/ノベル/配信等の画面からOCRで会話ログを構造化・保存するデスクトップアプリの開発
- **ゴール**: ホットキー1発で発話を記録し、編集・一括コピー・エクスポートまで完結できるツールの完成
- **制約**:
  - 開発期間: MVP 2-3週、beta 2-4週、1.0 2-6週
  - 技術スタック: Python / PySide6 / PaddleOCR
  - 対象OS: macOS（開発）、macOS/Windows（配布）

## リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| OCR精度不安定 | 高 | 前処理最適化、置換辞書、編集前提UX |
| macOS権限で詰む | 高 | 初回起動ガイド、権限検知と誘導UI |
| フルスクリーン問題 | 中 | 代替モード（ウィンドウキャプチャ） |
| 配布物が重い | 中 | OCRモデル最適化、lazy loading |
| pynputのクロスプラットフォーム問題 | 中 | OS別の分岐処理、フォールバック実装 |

## 品質基準

- [ ] 100件以上ログを取っても破綻しない
- [ ] 記録->編集->一括コピー->外部貼り付けがストレスなく回る
- [ ] プロファイル登録2箇所で運用できる
- [ ] 応答性: 0.3-1.5秒以内でログ追加完了
- [ ] メモリリークなし（長時間稼働テスト）
- [ ] データ安全: 異常終了時もデータ損失なし（JSONL追記形式）

## 技術スタック

| カテゴリ | 技術 | 備考 |
|----------|------|------|
| 言語 | Python 3.10+ | 型ヒント活用 |
| UI | PySide6 | Qt6ベース |
| 画像処理 | OpenCV | 前処理用 |
| OCR | PaddleOCR | 日本語対応 |
| 画面キャプチャ | mss | クロスプラットフォーム |
| ホットキー | pynput | グローバルホットキー |
| ビルド | PyInstaller | 配布用 |
| CI/CD | GitHub Actions | 自動ビルド・テスト |
