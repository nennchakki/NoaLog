# NoaLog 操作マニュアル

## キーバインド一覧

| キー | 機能 |
|------|------|
| `Cmd+Shift+R` | 範囲指定モード起動 |
| `Cmd+Shift+L` | OCR実行（キャプチャ） |
| `Enter` | 範囲選択確定 / 編集確定 |
| `ESC` | キャンセル |
| `Tab` | 領域タイプ切替（単一選択モード時） |

---

## 基本操作フロー

### 1. 起動

```bash
cd ~/NoaLog
source venv/bin/activate
noalog
```

### 2. 範囲指定（初回必須）

1. **`Cmd+Shift+R`** を押す → 画面全体にオーバーレイが表示される

2. **Step 1: ヘッダー領域を選択**
   - 話者名・所属が表示される領域をドラッグで囲む
   - **`Enter`** で確定（緑色で表示される）

3. **Step 2: ボディ領域を選択**
   - 本文（セリフ）が表示される領域をドラッグで囲む
   - **`Enter`** で確定

4. 完了 → ステータスバーにピクセル座標が表示される

### 3. OCRキャプチャ

1. キャプチャ対象のアプリケーションを表示
2. **`Cmd+Shift+L`** を押す
3. 指定した領域がOCRで読み取られ、ログに追加される

### 4. ログ編集

- **会話ログ一覧**: 項目を**ダブルクリック**で編集モード
- **詳細パネル**: 話者名/所属/本文を**ダブルクリック**で編集
- **`Enter`** で確定、**`ESC`** でキャンセル

## プロファイル管理

### 新規プロファイル作成

1. サイドバーの「**新規**」ボタンをクリック
2. プロファイル名を入力
3. 範囲指定（`Cmd+Shift+R`）で領域を設定
4. 保存

### プロファイル編集

1. サイドバーの「**編集**」ボタンをクリック
2. Profile Editorダイアログで設定変更
3. 保存

### プロファイル切替

- サイドバーまたはツールバーのドロップダウンから選択

## エクスポート

ログをファイルに出力:

- **テキスト (.txt)**: ファイル → エクスポート → テキスト
- **CSV (.csv)**: ファイル → エクスポート → CSV
- **JSON (.json)**: ファイル → エクスポート → JSON

## macOS 権限設定

NoaLogを使用するには以下の権限が必要です:

### 画面収録
1. システム設定 → プライバシーとセキュリティ → 画面収録
2. ターミナル（またはNoaLog）にチェックを入れる

### アクセシビリティ
1. システム設定 → プライバシーとセキュリティ → アクセシビリティ
2. ターミナル（またはNoaLog）にチェックを入れる

---

## トラブルシューティング

### ホットキーが反応しない
- アクセシビリティ権限を確認
- 他のアプリがショートカットを使用していないか確認

### OCRが動作しない
- 画面収録権限を確認
- 範囲が正しく設定されているか確認

### 文字認識精度が低い
- 対象領域を適切なサイズで選択
- コントラストの高い部分を選択
